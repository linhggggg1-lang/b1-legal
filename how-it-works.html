How It Works: End-to-End Workflow

B1 English Daily operates as an automated production pipeline that transforms raw vocabulary curriculum into polished TikTok educational videos. The application is run directly by the channel owner using verified developer API integrations.

Step 1: Curriculum & Vocabulary Selection (A1–B1)

Our educational database organizes vocabulary items according to the Common European Framework of Reference for Languages (CEFR). The pipeline filters and sequences terms across A1, A2, and B1 levels, pairing each with clear phonetic spelling, contextual meaning, and realistic sample sentences.

Step 2: Video Quiz Synthesis & Rendering

The rendering engine dynamically composes vertical short-form video assets (1080x1920):

  • Visual Composition: Generates question cards, multiple-choice options, countdown wheels, and highlighted reveal states.
  • Audio Integration: Generates neural speech pronunciation and countdown audio effects.
  • Quality Control: Runs automated checks on typography layout, audio sync, and text readability.

Step 3: Direct Publishing via TikTok Content Posting API

Once videos are rendered and verified, the application publishes them directly to the channel owner's authenticated TikTok account (@ting.anh.mi.ngy07) using the official TikTok Content Posting API.

  • Direct Channel Owner Publishing: The application does not solicit third-party users; the user of the application is the creator/owner of the TikTok channel.
  • Platform Compliance: Video titles, relevant educational hashtags, and mandatory AI-generated content disclosures are attached automatically.

System Architecture Overview

Input: CEFR B1 Curriculum Database → Engine: Media Rendering & Speech Synthesis → Distribution: TikTok Content Posting API → Destination: Official Channel Feed (@ting.anh.mi.ngy07)
